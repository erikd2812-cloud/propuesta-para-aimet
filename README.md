# Una pregunta para Aimet

Experiencia romántica interactiva, independiente de los demás proyectos.

## Estado actual

**Fase 1: prototipo visual de prueba.**

- Interfaz responsive para iPhone 11 y Android.
- Apertura misteriosa y recorrido de aproximadamente 45–60 segundos, según el ritmo de lectura.
- Paleta de neón rosa, fucsia, magenta y rojo.
- Partículas animadas de corazones y destellos.
- Sin música ni efectos de sonido.
- Dos desenlaces visuales para probar las respuestas.
- No envía ni almacena respuestas. Los botones son simulaciones locales.

## Vista previa

Cuando GitHub Pages esté activado, la página se publicará desde la raíz de la rama `main`.

## Próximas fases

1. Revisar la experiencia visual en Android y Safari de iPhone.
2. Construir el backend con autenticación de administrador y permisos de lectura exclusivos para el propietario.
3. Registrar respuestas mediante una función de servidor; nunca confiar en controles o claves privadas dentro del HTML.
4. Integrar notificaciones de WhatsApp mediante WhatsApp Business Platform o un proveedor oficial compatible.
5. Probar extremo a extremo antes de compartir el enlace real.

## Seguridad y privacidad

El repositorio contiene únicamente el prototipo público. No guardar aquí contraseñas, tokens, claves privadas, números de teléfono ni respuestas reales. El panel de administración no se incluirá en el sitio público. La versión real no se habilitará hasta que el backend y sus reglas de acceso estén configurados y verificados.
