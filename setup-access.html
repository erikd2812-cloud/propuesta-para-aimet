Configurar las dos contraseñas

Herramienta local de configuración inicial. Las contraseñas se procesan en este navegador con PBKDF2-SHA-256. No se envían a ningún servidor ni se guardan en esta página.

Elige dos contraseñas diferentes, de al menos 12 caracteres. La de Aimet la estableces tú y se la entregas. Solo tú podrás cambiar cualquiera de las dos desde el panel privado.

Después de generar el código, abre el SQL Editor de tu proyecto Supabase, pega el SQL y ejecútalo. El texto contiene únicamente hashes y sales aleatorias, no las contraseñas originales. No compartas el SQL ni una captura del resultado.
